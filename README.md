# Remix of FISAT Reimagined

FISAT WEBSITE REDESIGN — WEB DESIGN COMPETITION

We are redesigning the official website of Federal Institute of Science and Technology (FISAT), Angamaly, Kerala for a web designing competition.

The competition is primarily focused on frontend design, creativity, user experience, visual quality, responsiveness, animations and innovation.

This is a frontend-only project.

There is NO need for:

Backend

Database

Authentication

Real-time APIs

Admin panel

Use realistic static/mock data wherever necessary.

⚠️ STEP 0 — ASK FOR BRAND ASSETS BEFORE BUILDING

Before generating the website, FIRST identify which official FISAT branding assets are required and ask me to upload them.

Do NOT create fake versions of official FISAT branding.

Ask me for the following assets:

Required

Official FISAT logo

Prefer SVG

PNG is acceptable

Use the exact original logo

Do not redraw it

Ask optionally for:

Official FISAT logo in a version suitable for dark backgrounds

Official FISAT logo in a white/light version, if available

Official FISAT favicon

Official FISAT brand guidelines, if available

Official FISAT color palette, if available

Official FISAT department logos, if they are intended to be displayed

Official FISAT social-media icons/branding assets, if available

Official campus photographs

Official event/student-life photographs

If any of these are not available, continue using carefully designed placeholders only for non-logo assets.

Do NOT invent or recreate the FISAT logo.

After the assets are provided, use them consistently throughout the website.

BRANDING RULES

The official FISAT logo must remain unchanged.

Do NOT:

Redesign the logo

Recreate the logo

Change its colors

Stretch it

Distort it

Add unnecessary effects

Replace it with a generated logo

Use a fake university logo

Maintain the original aspect ratio.

The website itself should be creatively redesigned around the official identity.

The goal is:

Official FISAT identity + completely modern digital experience.

CORE CREATIVE CONCEPT

Create the website around the concept:

"FISAT — Where Your Journey Begins"

The website should represent the complete student journey:

Discover → Learn → Explore → Build → Experience → Launch

The website should feel like a digital campus, rather than a conventional college information website.

The judges should immediately feel:

"This is FISAT, but completely reimagined for the modern web."

DESIGN DIRECTION

Create a premium, modern technology-focused university website.

Use:

Strong typography

Large visual sections

Clean layouts

Spacious design

High-quality imagery

Subtle gradients

Modern cards

Glassmorphism only where appropriate

Smooth scrolling

Scroll-triggered animations

Micro-interactions

Hover effects

Animated statistics

Interactive elements

Smooth transitions

Responsive layouts

Avoid excessive decoration.

The design must remain professional and usable.

Do NOT make it look like a generic AI-generated university template.
